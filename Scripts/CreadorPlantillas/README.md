# PLANTILLA Y CREADOR DE PLANTILLAS DE PARA LOS EJERCICIOS DE SCRIPTING EN BASH

Para tener una mayor productividad en la ejecución de los ejercicios, se usó la siguiente plantilla

````bash
#!/bin/bash
# Script: DNS
# Autor:	Andrés
# Fecha:	AAAAMMDD
# Descripción: listar informacion en el DNS de una lista de direcciones web

````

Como ejercicio, cree un [creador de plantillas](./creadorplantilla.sh) para evitar el corta pega y la 
creación de archivo .SH en la misma carpeta donde se ejecuta el script.
Si quisiera cambiar el destino de guardado, solo hay que cambiarlo en el editor usado (nano, vscode, etc...)
